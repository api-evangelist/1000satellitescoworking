# 1000 Satellites

> 1000 Satellites GmbH is a German flex-office and coworking operator founded in 2019 in Mannheim, a
> spin-off of BASF's innovation unit Chemovator. It converts underused corporate office space into
> professionally operated "satellite" workspaces across the Rhein-Neckar region, Munich, Hamburg and
> Berlin. It is not a software company and publishes no product or developer API. Its only machine-readable
> surfaces are what its WordPress estate exposes: an anonymously readable content API, and — unusually for
> a business of this kind — a live remote Model Context Protocol server behind OAuth.

This file was GENERATED by API Evangelist on 2026-09-05 from the company's own public surface. 1000
Satellites does not publish an llms.txt of its own (https://1000satellites.de/llms.txt returns 404).

## What an agent can actually call

- [WordPress REST route index](https://1000satellites.de/wp-json): the provider's own route-discovery
  document, 41 namespaces, 528 routes. The source everything below was derived from.
- [Posts](https://1000satellites.de/wp-json/wp/v2/posts): company news, 28 items, anonymous, JSON.
- [Pages](https://1000satellites.de/wp-json/wp/v2/pages): location, service and legal pages, anonymous.
- [Media](https://1000satellites.de/wp-json/wp/v2/media): media library, anonymous.
- [Search](https://1000satellites.de/wp-json/wp/v2/search): site-wide search across public content.
- Also anonymous: categories, tags, comments, types, taxonomies, statuses.
- Paginate with `page` and `per_page` (max 100); read totals from the `X-WP-Total` and `X-WP-TotalPages`
  response headers. Add `wpml_language=en` for English, `de` for German — German is the default.

## What is gated

- [MCP server](https://1000satellites.de/wp-json/mcp/mcp-oauth-server): live remote MCP endpoint. An
  anonymous `tools/list` returns 401 `mcp_unauthorized`. Authorization is OAuth 2.1 authorization-code with
  PKCE (S256), one scope, `mcp`. The tool inventory is NOT published anywhere and is not listed here,
  because guessing it would be fabrication.
- [OAuth authorization server metadata](https://1000satellites.de/.well-known/oauth-authorization-server) (RFC 8414)
- [OAuth protected resource metadata](https://1000satellites.de/.well-known/oauth-protected-resource) (RFC 9728)
- `/wp/v2/users`, `/wp/v2/settings`, `/wp/v2/themes`, `/wp/v2/plugins`, `/wp/v2/menus` and all write
  methods return 401 to an anonymous request.

## What does not exist

- No OpenAPI, AsyncAPI, GraphQL, gRPC or SOAP contract published by the company.
- No developer portal, no API documentation, no API reference, no API key, no SDK, no CLI, no sandbox.
- No booking, availability, membership or location API. The Listdom plugin's public listings feed at
  `/wp-json/listdom/v1/public/listings` is advertised in the route index but returns HTTP 403.
- No status page, no changelog, no deprecation policy, no SLA, no security.txt, no agent card, no
  apis.json, no rate-limit headers.
